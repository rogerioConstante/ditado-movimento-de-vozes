# Ditado de Movimento das Vozes

Gerador de ditados de contrapontos a duas vozes, para desenvolver a
percepção dos **quatro tipos de movimento entre vozes**: paralelo, direto
(semelhante), oblíquo e contrário.

### ▶ [Abrir o ditado no navegador](https://rogerioconstante.github.io/ditado-movimento-de-vozes/) · 📖 [Manual do usuário](https://rogerioconstante.github.io/ditado-movimento-de-vozes/manual.html)

Funciona em qualquer navegador moderno, sem instalação.

## Como funciona

- Cada exercício tem **10 questões**; em cada uma, um contraponto a duas
  vozes é gerado automaticamente.
- A questão aparece de duas formas, sorteadas: **🎼 partitura + áudio** ou
  **🎧 somente áudio** (a partitura só é revelada na resposta).
- O aluno marca o movimento de cada transição; **Resposta** mostra a
  solução e **Próximo** passa à questão seguinte. O áudio pode ser repetido
  com **Tocar**.
- **Níveis 1 a 10:** definem o número de compassos de cada questão; a partir
  do nível 6 há tempo limite.
- Ao final, gera um **relatório em PDF** com a nota, o nível e o histórico de
  tentativas.

Detalhes e exemplos de cada tipo de movimento estão no [manual](manual.html).

## Usar no próprio computador

Baixe o repositório (**Code ▸ Download ZIP**), descompacte e abra o
`index.html` no navegador. É preciso estar conectado à internet: os timbres
são carregados de [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts).
